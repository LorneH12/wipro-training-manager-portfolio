# Lorne Hopkins Wipro Training Manager Portfolio

A separate portfolio for the Wipro Training Manager opportunity supporting GreenDot.

## Publish
Upload these files to the root of LorneH12/wipro-training-manager-portfolio. Enable GitHub Pages from the main branch root. No build step is required.

## Structure
The approved portfolio layout, imagery, navigation, project tabs and interactive sample player are retained. Role-specific content emphasizes training management, financial-services learning, coaching, employee readiness and feedback analysis. Resume and cover-letter PDF downloads are included.

## Independence
All visual assets, styles, fonts and scripts are included in this repository. Existing portfolios were not modified. Learning demonstrations remain linked to their existing course URLs. No new analytics collection is enabled.

## Evidence
Experience is based on the approved SRP resume and cover letter. No unverified team sizes, budget amounts, performance percentages or additional certifications were added. The 60,000 figure is the impacted program population, not a count of people personally trained. Portfolio courses are independent samples, not employer deliverables.
